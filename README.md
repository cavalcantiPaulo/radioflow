# radioflow

Este projeto está composto por arquivos que implementam uma rádio.  

Três tipos de estrutura de dados são utilizados:
- Fila:
  - Implementada na fila de músicas;
- Heap:
  - Implementado no ranking das músicas;
- Pilha:
  - Implementada no histórico das músicas.

O problema a ser solucionado foi tentar criar uma rádio (como descrito acima) em que se pudesse ter tanto uma lista das músicas que vão ser tocadas, podendo-se também curtir a música que está sendo tocada no momento.
